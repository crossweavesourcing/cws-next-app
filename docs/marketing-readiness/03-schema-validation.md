# Schema Validation

This document outlines the JSON-LD schemas generated by the application for SEO and AI search readiness.

## Schema Builders

The schema generation is centralized in `src/lib/seo/schema-builders.ts` to ensure type safety without bringing in bloated dependencies, and to guarantee clean JSON serialization into HTML.

### Organization & WebSite (Global Layout)
These schemas appear on every public page, injected by `src/app/(site)/layout.tsx`.
- **Organization**: Maps the site's address by resolving `bangladeshAddress` from the global CMS footer config.
  - **Omissions**: Phone, email, and social profiles are intentionally omitted to avoid fabricating unverified data.
- **WebSite**: Maps canonical `@id` strings to avoid duplication.
  - **Omissions**: The `SearchAction` element is intentionally omitted, as the public site does not offer a search interface.

### WebPage (Home Page)
The `WebPage` schema appears on the Home page (`src/app/(site)/page.tsx`), capturing the core meta description and title.

### Product & BreadcrumbList (Product Details)
Injected in `src/app/(site)/products/[slug]/page.tsx`.

- **BreadcrumbList**: Resolves `Home > Products > [Product Name]`. A visual representation was also added directly into the React component tree.
- **Product**: Resolves from the `ProductDocument` interface.
  - Identifies canonical image URLs.
  - Extracts the material from specifications if present.
  - **Critical Omissions**:
    - **`offers`**: The database does NOT store prices, currency, or inventory/stock status. Inventing this is prohibited.
    - **`aggregateRating` / `review`**: Not supported by the data model.
    - **`sku`**: Omitted since it is not explicitly captured.
    - **`brand`**: Substituted with `manufacturer` mapping back to the `Organization`.

## Validation Protocol

1. **Unit Testing**: Tests are located at `src/lib/seo/schema-builders.unit.test.ts`. They verify omissions and XSS safety (`<script>` escapes).
2. **Rich Results Test**: The best way to validate is deploying to a staging URL and running Google's [Rich Results Test](https://search.google.com/test/rich-results). Expect warnings for missing `offers` or `aggregateRating`, which is the intended behavior since this is a B2B manufacturer portfolio, not an e-commerce retail store.
