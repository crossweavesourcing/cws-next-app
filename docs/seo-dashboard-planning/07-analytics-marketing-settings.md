# Analytics and Marketing Configurations

## Safe for Dashboard (Database)
* **Search Console Verification ID**: `google-site-verification`.
* **Social Links**: URLs for LinkedIn, Twitter, etc.
* **UTM Campaign Builder**: Internal tool for marketers to generate links.

## Must Remain Environment Variables
* **GTM Container ID** (`NEXT_PUBLIC_GTM_ID`): Should remain in environment variables (`env.ts`) to ensure the correct container fires per environment (Staging vs Prod).
* **GA4 Measurement ID**.

## Content Marketing
* **FAQs**: Manageable as reusable blocks.
* **Testimonials / Case Studies**: Standard CMS collections.
