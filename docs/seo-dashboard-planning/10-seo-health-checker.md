# SEO Health-Checking System

## Dashboard Validations (Recommended)
1. **Missing Alt Text**: Warning. Checks if any product image lacks `altText`.
2. **Missing SEO Title**: Info. Page falls back to Name.
3. **Thin Content**: Warning. Product long description < 50 words.
4. **Draft in Sitemap**: Error (System-level prevention required).
5. **Missing Canonical**: Info. Auto-generates safely.
